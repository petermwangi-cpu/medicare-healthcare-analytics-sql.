# MediCare Hospital Analytics Dashboard

## Project Summary

This dashboard presents healthcare performance insights generated from a
SQL relational database.

The project analyzes synthetic hospital data to demonstrate healthcare
analytics workflows.

## Key Performance Indicators

-   Total patients
-   Healthcare providers
-   Appointment activity
-   Clinical records
-   Medication utilization
-   Billing performance

## Analytical Areas

### Patient Analytics

Analyzes demographics, insurance distribution, and patient populations.

### Clinical Analytics

Examines diagnoses, severity levels, treatments, and hospital stay
patterns.

### Operational Analytics

Evaluates appointment activity and doctor workload.

### Financial Analytics

Analyzes healthcare revenue and billing trends.
