# MediCare Hospital Analytics Database Using SQL

## Project Overview

A complete healthcare analytics database project demonstrating SQL database design, data modeling, and healthcare performance analysis.

## Business Scenario

MediCare Hospital requires data-driven insights into:

- Patient demographics
- Clinical outcomes
- Doctor workload
- Hospital operations
- Revenue performance

## Database Tables

- Patients
- Doctors
- Appointments
- Medical Records
- Medications
- Billing

## SQL Skills Demonstrated

- Database normalization
- Primary and foreign keys
- Complex joins
- Aggregations
- Common Table Expressions
- Window functions
- Views
- Healthcare KPI analysis

## How To Run

1. Create the database using SQL scripts.
2. Import CSV files.
3. Run analysis queries.
4. Review generated healthcare insights.

All records are synthetic and created for educational and portfolio purposes.
