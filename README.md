# MediCare Hospital Analytics Database Using SQL

## Overview

A healthcare analytics SQL project that designs a relational hospital
database and analyzes patient care, clinical outcomes, hospital
operations, and financial performance using SQL.

## Database Tables

-   Patients
-   Doctors
-   Appointments
-   Medical Records
-   Medications
-   Billing

## Skills Demonstrated

-   Relational database design
-   SQL joins
-   Aggregations
-   CTEs
-   Window functions
-   Views
-   Healthcare analytics

## Dataset

The project uses synthetic healthcare data created for analytics
practice and portfolio demonstration.
